One big number. One quiet line. A 2px spine that carries the odds.

Every fantasy chip is the same shape in every state — only the numbers, the tag, and the spine change. Score at 15px is the largest text on the rail. The bottom spine is ambient win probability: dim before kickoff, glowing while live, solid at final.

Implementation notes

  • chipBaseClasses gains relative overflow-hidden; spine is a new <ChipSpine pct state /> child — absolute, 2px, bottom inset-x-0
  • Spine fill: estimateWinProbability() (already in types.ts). Pre → fill at 35% opacity; live → full opacity + 2s glow pulse; final → 100% width, up/down color. Player chips: player_points / projected, clamped
  • Hero score: 15px comfort / 13px compact, font-bold tabular-nums; your team always left; final tints only your number (opponent stays fg-3)
  • Lead caret ▲/▼ renders only while live — pre has no lead, final already has W/L
  • States map 1:1 to matchup.status: preevent / midevent / postevent — no new data needed from the API
  • Motion respects the app's reduced-motion rule: pulse + glow disable under prefers-reduced-motion, flash falls back to a static green tint
